استرجاع نظيف للموقع

مهم جدًا:
لا تستبدل الملفات فوق المشروع القديم فقط، لأن ملفات التخريب الزائدة ستظل موجودة.

الخطوات:
1) اقفل السيرفر.
2) داخل فولدر المشروع عندك احذف هذه العناصر بالكامل إن وجدت:
   - src
   - dist
   - node_modules/.vite

3) فك هذا الملف وانسخ الملفات كلها مكان ملفات المشروع.

4) شغل:
   npm install
   npm run dev

5) افتح المتصفح واعمل:
   Ctrl + Shift + R

لو أنت على Windows ومش عايز تستخدم أوامر:
- افتح فولدر المشروع.
- احذف مجلد src بالكامل.
- انسخ src من هذا الملف مكانه.
- احذف dist إن وجد.
- احذف node_modules/.vite إن وجد.
- شغل السيرفر من جديد.
