# مصفوفة اختبار الأمان بعد الرفع

## حساب الطالب

- افتح `/admin` بحساب طالب: يجب أن تظهر رسالة منع.
- حاول تعديل الدرجة من المتصفح: يجب أن تفشل قواعد Firestore.
- حاول قراءة `admin_audit_logs`: يجب أن تفشل.
- ادخل امتحان، اكتب إجابة، افصل الإنترنت: يجب ظهور شريط الاتصال واستمرار الحفظ المحلي.
- أعد الإنترنت: يجب مزامنة آخر نسخة محفوظة.

## حساب الأدمن

- افتح `/admin`: يجب أن تعمل اللوحة.
- فعّل/عطّل طالب: يجب أن تنفذ Function وتظهر في `admin_audit_logs`.
- وافق/ارفض طلب دفع: يجب أن تنفذ Function وتظهر في `admin_audit_logs`.
- احذف امتحان تجريبي: يجب أن تنفذ Function وتظهر في `admin_audit_logs`.

## أوامر الفحص

```bash
npm run security:smoke
npm run production:check
```
