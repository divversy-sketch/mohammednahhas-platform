# Nahhas Platform Docs

الوثائق الحالية مقسمة كالتالي:

- `reports/`: تقارير المراحل النشطة والقرارات التنفيذية الحديثة.
- `architecture/`: ملاحظات المعمارية والأمان.
- `archive-notes/`: ملاحظات قديمة محفوظة للرجوع فقط.
- `archive-code/`: كود أو أجزاء قديمة غير مستخدمة مباشرة.

لأي تطوير جديد، أضف تقريرًا مختصرًا داخل `docs/reports` بدل إضافة ملفات كثيرة في جذر المشروع.
