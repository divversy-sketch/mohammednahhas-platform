# إصلاح وضوح كارت القيادة في V2

تم إصلاح مشكلة ظهور نص أبيض فوق خلفية بيضاء في كارت القيادة داخل لوحة الأدمن.

## السبب

القواعد العامة لكروت V2 كانت تضيف خلفية زجاجية بيضاء باستخدام `!important`، وهذا غطّى خلفية الكارت الداكنة بينما بقي النص أبيض.

## التعديل

- إضافة class واضح لكارت القيادة: `v2-admin-hero-card`.
- تثبيت خلفية داكنة للكارت داخل CSS.
- تثبيت ألوان النصوص والأزرار داخل الكارت لضمان القراءة.

## الملفات المعدلة

- `src/admin/v2/AdminV2PageFrame.jsx`
- `src/styles/v2-redesign.css`
