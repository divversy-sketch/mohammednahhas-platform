# ملخص التعديلات المنفذة

## تنظيف التضخم

- نقل ملفات التطبيقات القديمة الضخمة خارج `src` إلى `docs/archive-code` حتى لا تدخل في التطوير اليومي أو الاستيراد بالخطأ.
- إزالة النسخ المكررة غير المستخدمة من مكونات الطالب/الأدمن عندما توجد نسخة مشتركة فعّالة داخل `src/shared/platformParts`.
- تنظيف الاستيرادات الزائدة في ملفات `src` لتقليل الضوضاء وتحسين قابلية الصيانة.

## تحسين الأداء

- تفعيل lazy loading لتطبيق الطالب وتطبيق الأدمن موجود بالفعل عبر `AppRoot`، وتم تعميقه داخل كل تطبيق.
- جعل صفحات/مناطق ثقيلة تتحمل عند الطلب مثل لوحة الطالب، لوحة الأدمن، صفحة الهبوط، صفحة الدخول، مشغل الامتحان، عارض الفيديو، عارض المحتوى التفاعلي، مركز الكورسات، وتحليلات الطالب.
- إضافة chunk مستقل لـ `pdfjs-dist` في إعدادات Vite لتقليل ضغط الحزمة الأساسية.

## تجهيز الإنتاج

- إزالة Tailwind CDN من `index.html` والاعتماد على بناء Tailwind المحلي.
- نقل مفتاح App Check إلى متغير بيئة `VITE_RECAPTCHA_V3_SITE_KEY` بدل كتابته مباشرة في الكود.
- إضافة `.env.example` لتوضيح المتغيرات المطلوبة.
- تحسين رسائل أخطاء تسجيل الدخول والتسجيل لتظهر للطالب بشكل مفهوم بدل رسائل Firebase الخام.

## ملاحظات تشغيل

بعد استلام النسخة شغّل محليًا:

```bash
npm install
npm run build
npm run lint
npm run production:check
```

لو ظهر خطأ من `lint` غالبًا سيكون بسبب كود قديم كان مخفيًا وسط الاستيرادات الزائدة، ويُفضّل إصلاحه بدل تعطيله.
