# Student Dashboard Cleanup

التحديث ده بيعمل:

- دمج شاشة الاستكمال مع خطة اليوم في شاشة واحدة.
- حذف شاشة الإشعارات من صفحة الطالب.
- تثبيت الترحيب وعدادات المحاضرات/الامتحانات/النتائج في أول الصفحة فقط.
- الجملة الافتتاحية تتغير تلقائيًا حسب حالة الطالب.
- إزالة كروت الأقسام المكررة من الصفحة الرئيسية.

أوامر التشغيل:

```bash
npm run build
git add .
git commit -m "Clean student dashboard continuation and notifications"
git push origin main
```
