# فصل لوحة الإدارة - المرحلة الحالية

تم تنفيذ فصل عملي داخل نفس مشروع Vite الحالي كمرحلة انتقالية قبل الفصل النهائي إلى مشروعين مستقلين.

## ما تم تنفيذه

1. مسار منفصل للوحة الإدارة:
   - لوحة الإدارة تعمل من `/admin`.
   - واجهة الطالب تعمل من `/student` أو المسار الرئيسي.
   - أي طالب يحاول فتح `/admin` تظهر له شاشة منع صلاحية بدل لوحة الإدارة.

2. صلاحيات الإدارة لم تعد تعتمد على ظهور الواجهة فقط:
   - يتم السماح للأدمن إذا كان البريد هو `mido16280@gmail.com`.
   - أو إذا كان للـ UID مستند داخل collection باسم `admins`.
   - الأفضل لاحقًا إزالة الاعتماد على البريد الثابت والاكتفاء بمستندات `admins` أو Custom Claims.

3. قواعد Firebase مضافة للمشروع:
   - `firestore.rules`
   - `database.rules.json`
   - `storage.rules`
   - وتم ربطهم داخل `firebase.json`.

4. تم إغلاق مجموعات الذكاء الاصطناعي والبث المباشر التي تم حذفها من النسخة المنظفة:
   - `ai_usage`
   - `ai_exam_results`
   - `ai_generated_exams`
   - `live_sessions`
   - `live_attendance`
   - ومجموعات `rafiq_*`.

5. تم تضييق تحديث الطالب لنتائج الامتحان قدر الإمكان:
   - الطالب لا يفترض أن يعدل الدرجة أو النسبة.
   - يسمح له فقط بتحديث حقول الإجابة والحفظ التلقائي والتسليم.

## طريقة التشغيل

- افتح لوحة الطالب من:
  `/student`

- افتح لوحة الإدارة من:
  `/admin`

- للنشر على Firebase Hosting تم إضافة rewrite داخل `firebase.json` حتى تعمل المسارات المباشرة بعد الرفع.

## مهم قبل النشر

1. راجع أسماء الحقول الفعلية في نتائج الامتحانات.
   لو التطبيق يستخدم أسماء مختلفة للحفظ التلقائي، قد تحتاج إضافة هذه الحقول داخل `safeStudentExamResultUpdate()` في `firestore.rules`.

2. أنشئ مستند للأدمن داخل Firestore:

```txt
collection: admins
document id: UID الخاص بالأدمن
```

يمكن أن يحتوي المستند على:

```json
{
  "email": "mido16280@gmail.com",
  "role": "owner",
  "createdAt": "server timestamp"
}
```

3. يفضل في المرحلة التالية نقل عمليات الحذف والتعديل الحساسة إلى Cloud Functions.

## المرحلة النهائية المقترحة لاحقًا

بعد استقرار النسخة الحالية، يتم فصل المشروع إلى:

```txt
apps/student
apps/admin
packages/shared
```

أو مشروعين منفصلين تمامًا:

```txt
student-platform
admin-dashboard
```

النسخة الحالية هي مرحلة آمنة ومنظمة أكثر، لكنها ليست الفصل النهائي الكامل على مستوى build مستقل لكل تطبيق.
