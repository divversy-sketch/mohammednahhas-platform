# Nahhas UI Cleanup Patch

التعديلات:
- حذف زر "مراسلة الإدارة" العائم من واجهة الطالب.
- الحفاظ على تصميم الموقع كما هو بدون تغيير في الهوية أو الألوان.
- الإبقاء على Popup الرسائل المهمة من الإدارة على الشاشات الكبيرة فقط.
- تضمين ملفات app/features/shared/services/utils معًا لتجنب أي Missing Imports.

طريقة التطبيق:
1. فك الضغط فوق مجلد المشروع.
2. وافق على Replace للملفات.
3. شغّل: npm run build
