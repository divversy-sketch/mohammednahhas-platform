# مرحلة التطوير الموحد للأقسام الموجودة

تم تنفيذ التطويرات داخل الأقسام الأصلية بدون إنشاء تبويبات جديدة غير لازمة.

## الاشتراكات والدفع
- إنشاء باقات اشتراك حقيقية.
- إيقاف/تفعيل/حذف الباقات.
- قبول ورفض طلبات الدفع.
- تفعيل اشتراك الطالب تلقائيًا عند قبول الدفع.
- تنبيه الطلاب الذين أوشك اشتراكهم على الانتهاء.
- تصدير طلبات الدفع CSV.

## الكورسات التعليمية
- خريطة وحدات/أسابيع للكورس.
- تحديد المرحلة، أسبوع النشر، تاريخ النشر، شرط سابق، وحالة النشر.

## بنك الأسئلة
- إضافة سؤال يدوي.
- استيراد CSV.
- فلترة الأسئلة حسب المرحلة، الفرع، الصعوبة، والبحث.
- حذف سؤال.
- تصدير بنك الأسئلة CSV.
- توليد مسودة امتحان من بنك الأسئلة في collection باسم `exam_drafts`.

## تقارير الطلاب
- فلترة الطلاب المحتاجين متابعة حسب المرحلة.
- تصدير تقرير الطلاب المتأخرين CSV.
- إرسال تنبيه متابعة جماعي للطلاب المتأخرين.

## الإشعارات
- إرسال إشعار لكل الطلاب أو مرحلة محددة أو طلاب محددين.
- حساب عدد المستلمين المتوقع قبل الإرسال.
- دعم وقت جدولة محفوظ في البيانات.

## إعدادات المنصة/الموبايل
- حفظ إعدادات تجربة الموبايل: شريط سفلي، كروت مختصرة، توفير بيانات، وضع امتحان آمن، زر تثبيت التطبيق.

## الدعم والرسائل
- عرض تذاكر الطلاب.
- الرد على التذكرة.
- إغلاق التذكرة.

## الأمان و Audit Log
- تسجيل العمليات الجديدة في `admin_client_logs`.
- تأكيد قبل الحذف في العمليات الحساسة.

## اختبارات
تم تشغيل:
- `npm run source:health`
- `npm run build`
- `npm run security:smoke`
- `npm run bundle:report`
