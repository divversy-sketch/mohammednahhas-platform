# قائمة الفحص النهائية

## قبل النشر

- [ ] `npm install` تم بنجاح.
- [ ] `npm run source:health` نجح.
- [ ] `npm run build` نجح.
- [ ] `npm run production:ready` نجح أو تم تشغيل خطواته واحدة واحدة.
- [ ] لا توجد شاشة بيضاء في local preview.
- [ ] لا توجد أخطاء حمراء مؤثرة في Console.
- [ ] ملف `.env` يحتوي مفاتيح Firebase المطلوبة.
- [ ] مفتاح `VITE_RECAPTCHA_V3_SITE_KEY` مضاف في الإنتاج إن كنت ستفعل App Check.

## بعد النشر

- [ ] رابط Vercel يفتح الصفحة الرئيسية.
- [ ] دخول الطالب يعمل.
- [ ] دخول الأدمن يعمل.
- [ ] امتحان الطالب يعمل بعد refresh.
- [ ] نتيجة الامتحان تظهر.
- [ ] قبول الدفع يفعل الطالب.
- [ ] الإشعارات تصل للطالب.
- [ ] تذاكر الدعم تعمل.
- [ ] System Health يظهر داخل إعدادات المنصة.
- [ ] Audit Log يسجل العمليات الحساسة.

## بيانات يجب مراجعتها دوريًا

- [ ] `system_errors`
- [ ] `performance_metrics`
- [ ] `admin_audit_logs`
- [ ] `payment_requests`
- [ ] `student_chats`
- [ ] نتائج الامتحانات في المسارات القديمة والجديدة.
