# تطوير بنك الأسئلة - استيراد النحو والبلاغة

تم تطوير تبويب بنك الأسئلة ليستقبل ملفات أسئلة كاملة للنحو والبلاغة، وليس درسًا واحدًا فقط.

## الأنواع المدعومة

- TXT
- DOCX
- PDF نصي

> ملاحظة: تظليل الإجابة مدعوم عمليًا في DOCX. أما PDF فالأفضل استخدام علامة `*` أو سطر `الإجابة:` لأن التظليل في PDF غالبًا لا يظهر كنص قابل للقراءة.

## طريقة 1: علامة النجمة

```txt
# النحو
## المنادى
س1: يا طالبَ العلم اجتهد. نوع المنادى هو:
أ) نكرة مقصودة
ب) مضاف *
ج) شبيه بالمضاف
د) علم مفرد
شرح: لأنه أضيف إلى كلمة العلم.

# البلاغة
## التشبيه
س1: العلم نور. نوع الصورة البلاغية:
أ) تشبيه بليغ *
ب) استعارة
ج) كناية
د) طباق
```

## طريقة 2: التظليل في Word

في ملف DOCX يمكن تظليل سطر الإجابة الصحيحة بالكامل، مثل:

```txt
أ) نكرة مقصودة
ب) مضاف     ← يتم تظليل السطر في Word
ج) شبيه بالمضاف
د) علم مفرد
```

## طريقة 3: سطر الإجابة

```txt
س: أي الجمل الآتية بها منادى علم مفرد؟
أ) يا محمدُ اجتهد
ب) يا طالبَ العلم اجتهد
ج) يا رجلاً ساعدني
د) يا قارئًا القرآن تدبر
الإجابة: أ
شرح: لأنه اسم علم مفرد مبني على الضم.
```

## التصنيف التلقائي

استخدم عناوين مثل:

```txt
# النحو
## المنادى

# البلاغة
## التشبيه
```

سيتم حفظ كل سؤال في `question_bank` مع الحقول:

- branch: النحو / البلاغة
- topic أو lesson: المنادى / التشبيه / إلخ
- tags
- correctIdx
- explanation
