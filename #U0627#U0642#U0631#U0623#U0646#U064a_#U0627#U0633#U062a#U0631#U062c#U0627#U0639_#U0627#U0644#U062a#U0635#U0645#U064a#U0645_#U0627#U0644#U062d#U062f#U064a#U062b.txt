استرجاع التصميم الحديث

هذه النسخة ليست الرجوع القديم.
هذه نسخة كاملة للموقع مع استرجاع تصميم الصفحة الرئيسية وصفحات تسجيل الدخول/إنشاء الحساب الحديثة قبل تعديل صفحة الطالب.

طريقة التركيب الصحيحة:
1) اقفل السيرفر.
2) احذف من مشروعك:
   - src
   - dist
   - node_modules/.vite
3) فك هذا الملف وانسخ محتواه مكان مشروعك.
4) شغل:
   npm install
   npm run dev
5) في المتصفح:
   Ctrl + Shift + R

مهم:
لا تنسخ فوق الملفات بدون حذف src، لأن الملفات المخربة الزائدة ستظل موجودة.
